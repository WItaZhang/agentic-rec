\noindent\textbf{Adaptive Evidence for Recommendation}
\hfill\href{https://github.com/WItaZhang/agentic-rec}{GitHub}
\begin{itemize}
  \item Built a reproducible temporal recommendation pipeline on 70,922 deduplicated Amazon review events, comparing popularity, ItemKNN, and a causal Transformer with GPT-4.1 mini reranking under immutable top-200 candidates and leakage checks.
  \item Trained four cost-aware utility routers on real action outcomes for 1,045 earlier-period users with inverse-inclusion weights; froze model and policy selection on 3,318 validation users and evaluated fixed, rule, random, and learned policies on 3,572 held-out users.
  \item Audited evidence value with paired bootstrap intervals, provider token accounting, equal-token content controls, and stronger-base ablations. Full evidence lowered test NDCG@10 by 0.01526 versus ItemKNN; retained the validation-selected sequence model and published reproducible outcomes, costs, and failure analyses.
\end{itemize}
