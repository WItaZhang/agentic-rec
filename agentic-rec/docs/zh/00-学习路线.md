## 三层认知

读完之后，你应该能在三个层次上讲清这个领域：

**第一层，一句话。** Agentic 推荐系统就是让一个大语言模型"带着循环"去做推荐：它可以查工具、记住过去、反思错误、和用户多轮对话，而不是一次打分就结束。

**第二层，一张图。** 所有这类系统都是同一个循环：

```
观察 ──► 画像 ─┐
         记忆 ─┼─► 规划（可以调用工具）─► 动作
         任务 ─┘                        │
                                         ▼
              反馈 ─► 反思 ─► 写回记忆
```

不同论文的区别在于挂了哪些零件、零件怎么实现、以及整个系统怎么被优化。

**第三层，一份配置。** 本项目把上面的循环做成了代码，每个零件都是可选参数。一篇论文的架构等于一份十几行的 TOML 配置文件。看懂 `configs/` 里的十一个文件，就等于看懂了十一篇论文的骨架。

## 学习建议

- 01 和 02 如果已经熟悉可以跳过，但建议至少扫一遍术语约定。
- 04 很长，第一遍只读每篇的"一句话"和"解决什么问题"，第二遍再看"怎么做"。
- 07 和 08 边读边打开代码。文档里提到的每个类都能在包里找到，命名一致。
- 每一节末尾有"自测问题"，能回答出来再往下走。
