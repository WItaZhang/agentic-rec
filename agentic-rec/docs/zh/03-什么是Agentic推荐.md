# 03 · 什么是 Agentic 推荐

## 1. 两条路线的分界

大模型进入推荐领域有两条路线，容易混淆，先分清。

**路线一：LLM for Recommendation（LLM 辅助推荐）。** 把大模型当一个更强的零件用：用它生成物品描述、提取用户特征、对候选重排、或者直接微调成一个打分器。特点是**调用一次就结束**，模型没有自己的控制流。这条路线不在本项目范围内。

**路线二：Agentic Recommendation（Agent 式推荐）。** 给大模型一个循环，让它自己决定要不要查历史、要不要调用召回模型、要不要追问用户、要不要复盘上一轮为什么失败。这才是本项目的主题。

判断一篇论文属于哪条路线，看三个问题：模型能不能自己决定走几步？有没有跨步骤的记忆？它的动作会不会改变环境并反馈回来？三个都是"是"，就是 Agentic。

## 2. Agent 能扮演的角色

把 Agent 放进推荐系统，不只有"当推荐器"这一种用法。这是理解整个领域最重要的一张表：

| 角色 | Agent 是什么 | 解决什么问题 | 代表工作 |
|---|---|---|---|
| **Agent 作为推荐器** | 负责选物品、和用户对话、把传统模型当工具调用的那个系统 | 传统推荐不会对话、不会解释、不会用外部知识 | Chat-REC、RecMind、InteRecAgent、MACRec、BiLLP、AgenticRec |
| **Agent 作为用户** | 一个模拟出来的人，会浏览、点击、评分、聊天、离开 | 离线指标衡量不了用户体验，上线测试太贵 | RecAgent、Agent4Rec、SimUSER、RecoWorld 的用户侧 |
| **Agent 作为物品** | 每个物品维护一段会自我更新的描述，和用户 Agent"协商" | 把协同过滤搬到文本空间 | AgentCF、Rec4Agentverse |
| **用户侧助理** | 站在用户一边的个人 Agent，对平台的推荐结果重排、过滤 | 平台的利益和用户的利益不一致 | RAH、iAgent |
| **共同演化的一对** | 推荐器 Agent 和用户 Agent 从同一批交互轨迹里一起训练 | 让 Agent 真正从互动中学习而不只是改 prompt | RecoWorld、CoARS |

前两种占了绝大多数论文。多 Agent 系统往往同时包含几种角色。

## 3. 按拓扑分类

- **单 Agent 带工具**：一个 LLM，一组工具。RecMind、InteRecAgent、ToolRec、BiLLP、iAgent、AgenticRec。
- **经理与工人**：一个 Agent 派活给几个专职 Agent。MACRec 的经理、用户分析师、物品分析师、反思者、搜索者；AgentRec 的协调者。
- **提案与选择**：几个 Agent 各出一个回复，一个选择器挑。MACRS 的按对话行为分工的响应者；MACS 的 LLM 加搜索引擎混合。
- **群体**：很多用户 Agent 和一个推荐器互动。Agent4Rec 的一千个 Agent；AgentRecBench 的模拟世界。

## 4. 按优化方式分类

- **只靠 prompt**：模型参数不变，靠 prompt 设计、记忆检索、文字反思来改变行为。2023 到 2024 年几乎全部。
- **监督轨迹微调**：用工具调用轨迹微调模型。ToolRec 的代理用户微调；AgenticRec 的第一阶段。
- **从交互中强化学习**：Rec-R1 把固定推荐器的输出当奖励；RecoWorld 和 CoARS 对着模拟用户训练；ReRec 对推理助手做强化微调；RecRM-Bench 专门研究奖励模型该衡量什么。

从第一类到第三类的迁移，是 2025 到 2026 年最清晰的趋势。

## 5. 时间线

用五句话记住这个领域的演进：

1. **2023 上半年**，Chat-REC 证明 ChatGPT 可以对传统推荐结果重排和解释。
2. **2023 下半年**，RecMind 和 InteRecAgent 给出完整的"规划 + 记忆 + 工具"设计；RecAgent 和 Agent4Rec 用 Agent 造模拟用户。
3. **2024 年**，多 Agent（MACRec、MACRS）和长期规划（BiLLP）出现；"模拟器到底靠不靠谱"开始被质疑。
4. **2025 年**，基准和环境成熟（AgentRecBench、RecoWorld），用户侧 Agent（iAgent）出现，强化学习入场（Rec-R1）。
5. **2026 年**，可验证的评测（τ-Rec）、奖励模型基准（RecRM-Bench）、参数化学习取代文字记忆（CoARS、AgenticRec）。

## 6. 三篇已有综述

- Peng 等（2025，EMNLP Findings）：分为面向推荐器、面向交互、面向模拟三类。
- Lin 等（2026）：按自主程度分级，三种范式：Agent 辅助推荐、Agent 作为推荐器、Agent 作为用户模拟器。
- Huang 等（2025）：多模态视角。

本项目的分类和三者兼容，但组织方式是"Agent 扮演什么角色"和"Agent 由什么零件组成"，因为这两点直接决定工程实现。
