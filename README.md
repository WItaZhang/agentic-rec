## Research project plan

[Adaptive Evidence Acquisition for Agentic Recommendation](agentic-rec/docs/adaptive-evidence/README.md) is a detailed implementation and experiment plan for a real-data project: learning when additional user-history or item evidence is worth its inference cost. It covers temporal evaluation, strong baselines, routing and stopping, resource accounting, milestones, and evidence-backed resume templates. The plan is written in Chinese with English technical terms and resume examples; it documents proposed work, not completed adaptive-policy results.
